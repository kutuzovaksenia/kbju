# База знаний нутрициолога — выжимка для AI-подсказок

## КЛЕТЧАТКА (норма 25-30г для женщин)
- Норму клетчатки сложно добирать — большинство людей не добирают даже половины
- Огурцы, помидоры, листья салата дают мало клетчатки — не стоит на них рассчитывать
- Лучшие источники клетчатки: бобовые (чечевица, нут, фасоль), отруби, льняное семя, семена чиа, овёс, гречка, яблоки, груши, брокколи, капуста, морковь
- Растворимая клетчатка (яблоки, цитрусовые, бобовые, чиа) — превращается в гель, кормит микробиом, снижает холестерин
- Нерастворимая клетчатка (отруби, цельнозерновые, овощи) — ускоряет транзит, чистит кишечник
- Зелень лучше добавлять в смузи, фарш, котлеты, супы — так проще съесть нужный объём
- При нехватке клетчатки: добавить в следующий приём бобовые, льняное семя в йогурт/кашу, яблоко с кожурой, горсть орехов
- Резко увеличивать клетчатку нельзя — вводить постепенно, иначе вздутие

## БЕЛОК (норма 94г)
- Белок — самый насыщающий макронутриент, снижает аппетит и тягу к сладкому
- Лучшие источники: куриная грудка, индейка, творог 5%, греческий йогурт, яйца, рыба (лосось, треска, тунец), говядина, бобовые
- Белок нужно распределять равномерно по приёмам пищи — не копить на ужин
- При нехватке белка к вечеру: творог, греческий йогурт, яйца, кефир с льняным семенем
- Добавки: протеин можно использовать как дополнение, но лучше получать из еды
- Бобовые — хороший источник белка + клетчатка в одном продукте

## ЖИРЫ (норма 52г)
- Жиры нельзя убирать — нужны для гормонов, кожи, усвоения витаминов
- Хорошие жиры: авокадо, оливковое масло холодного отжима, рыба жирных сортов, орехи, семена, яйца
- Масла: оливковое — для заправки салатов и низкотемпературного приготовления; кокосовое и топлёное — для жарки
- Омега-3: жирная рыба 2-3 раза в неделю или добавка
- Трансжиры (маргарин, фастфуд, промышленная выпечка) — исключить

## УГЛЕВОДЫ (норма 139г)
- Углеводы — основной источник энергии, не враг при правильном выборе
- Медленные углеводы: гречка, овёс, булгур, киноа, бурый рис, бобовые, цельнозерновой хлеб
- Быстрые углеводы (белый хлеб, сахар, сладкое) — лучше минимизировать или есть после тренировки
- Фрукты — хороший источник углеводов + клетчатка + витамины, не нужно бояться
- Овощи — некрахмалистые можно есть без ограничений

## ПЕРЕКУСЫ
- Хороший перекус: белок + клетчатка или белок + жир (дольше насыщает)
- Варианты: творог с ягодами, яблоко с орехами, греческий йогурт, яйцо с овощами, хумус с морковью/огурцом
- Протеиновые батончики: читать состав — не менее 15г белка, минимум сахара
- Рисовые хлебцы — почти нет питательной ценности, быстро поднимают сахар; если есть — добавить белковое
- Сухофрукты — концентрированный сахар, маленькая горсть
- Орехи — насыщающий перекус, но калорийные (горсть ~30г)

## МЕТОД ТАРЕЛКИ (основа каждого приёма пищи)
- 1/2 тарелки — некрахмалистые овощи (брокколи, огурцы, помидоры, зелень, кабачки)
- 1/4 тарелки — белок (мясо, рыба, яйца, бобовые, творог)
- 1/4 тарелки — сложные углеводы (гречка, рис, картофель, хлеб)
- Добавить полезный жир: оливковое масло, авокадо, орехи

## ЗАГОТОВКИ (экономия времени)
- Готовить сразу на 3-5 порций: каши, запечённые овощи, мясо/рыба
- Замораживать: соусы для шакшуки, супы, котлеты, бобовые после варки
- Хранить в холодильнике готовые компоненты для быстрой сборки тарелки
- Лосось: запечь в духовке 180° 15-20 минут, использовать 3-4 дня

## ВОДА
- Норма: 30-35 мл на кг веса (примерно 1.5-2л для большинства)
- Пить до ощущения жажды, не ждать жажды
- Утром натощак — стакан воды
- Перед едой стакан воды помогает есть меньше
- Чай, кофе без сахара — считается в водный баланс частично
- Отёки чаще от нехватки воды и соли, а не от её избытка

## ВРЕМЯ ПРИЁМОВ ПИЩИ
- Интервальное голодание: окно питания 8-10 часов (например 10:00-20:00)
- После 20:00: если голодна — лёгкий белок (кефир, творог, яйцо), не тяжёлые углеводы
- Не пропускать завтрак — задаёт тон обмену веществ
- 3 основных приёма + 1-2 перекуса — оптимально

## ПИТАНИЕ В РЕСТОРАНАХ И В ГОСТЯХ
- Метод тарелки работает везде — выбирать блюда по тому же принципу
- Попросить соус отдельно, выбирать запечённое/гриль вместо жареного
- Не голодать перед выходом — придёшь голодная и съешь лишнего
- Алкоголь: блокирует жиросжигание, повышает аппетит
- В путешествиях: искать супермаркеты, брать с собой орехи/протеин

## ОБМЕН ВЕЩЕСТВ
- 60-70% энергии тело тратит в покое (базальный метаболизм)
- Метаболизм не "сломан" — он адаптируется к дефициту
- Не есть меньше 1200 ккал — тело переходит в режим экономии
- Силовые тренировки повышают базальный метаболизм
- Сон — критически важен для обмена веществ и похудения

## МИКРОБИОМ И КИШЕЧНИК
- Разнообразие растительных продуктов — главное для здорового микробиома
- Ферментированные продукты: кефир, йогурт, квашеная капуста
- Клетчатка кормит полезные бактерии
- Пробиотики из еды предпочтительнее добавок

## КОЖА, ВОЛОСЫ, НОГТИ
- Коллаген: костный бульон, желатин, витамин С для синтеза
- Биотин: яйца, орехи, печень
- Цинк: тыквенные семечки, мясо, бобовые
- Омега-3 (жирная рыба) — увлажнение кожи изнутри
- Дефицит белка — первая причина плохого состояния волос и ногтей

## ПИТАНИЕ ВО ВРЕМЯ ТРЕНИРОВОК
- До тренировки за 1.5-2 часа: углеводы + белок (каша с яйцом, рис с курицей)
- После тренировки в течение 30-60 минут: белок + углеводы (творог с фруктом, курица с гречкой)
- Во время длительных тренировок: можно банан, финики

## ДОБАВКИ
- Витамин D — большинству нужен, особенно осенью-зимой
- Омега-3 — если рыба реже 2 раз в неделю
- Магний — при стрессе, плохом сне, судорогах
- Железо, B12 — проверить анализы, не принимать без дефицита
- Остальное — из еды, не из таблеток

## ПРИВЫЧКИ И ПСИХОЛОГИЯ
- Не делать продукты "запрещёнными" — усиливает тягу
- 80/20: 80% — питательная еда, 20% — без ограничений
- Стресс вызывает тягу к сладкому и жирному (кортизол)
- Есть медленно, без телефона — мозг получает сигнал насыщения через 20 минут
- Фото еды перед едой — помогает осознанности
